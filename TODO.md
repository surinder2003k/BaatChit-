# BaatChit Outcomes

- [x] **No-auth name entry:** Website opens with a popup asking for the visitor's name; after submitting, the name is saved in that browser and used on messages. Do not require Manus login or any account authentication.
- [x] **Shared live text chat:** Any visitor can send messages, and every other open browser/tab sees new messages without refreshing through fast cloud-backed synchronization.
- [x] **24-hour reset:** A visible timer at the top shows the remaining time; after 24 hours the complete chat is cleared and a new chat session begins.
- [x] **Photo/video sharing:** Users can attach and send only photos and videos; media appears inside the chat with image preview or video playback.
- [x] **Full-screen chat layout:** The chat occupies almost the entire screen with a scrollable message area and a compact bottom composer containing text input, send control, and file attachment control.
- [x] **Theme control:** System light/dark theme is the default, with a compact top-corner manual light/dark toggle.
- [x] **Responsive professional UI:** Keep the interface clean, simple, modern, and usable on mobile and desktop without unnecessary sections or decoration.
- [x] **Multi-file composer:** Multiple photos/videos can be selected together, previewed in the composer, removed individually, and sent while the send control enables correctly.
- [x] **Media viewer:** Videos use native full controls including timeline and fullscreen; photos render without a bulky border and open in a zoomable, swipe/button-navigable lightbox with close control.
- [x] **Message actions:** Text messages support copy, reply, swipe-to-reply, press-and-hold menu, emoji picker, and persisted live emoji reactions.
- [x] **Cross-context validation:** Check the flow in at least two browser contexts/tabs for name entry, live sync, attachments, theme, countdown, and no-refresh behavior; fix confirmed issues.
